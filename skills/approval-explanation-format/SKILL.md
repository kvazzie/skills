# Approval explanation format

When a skill requires confirmation or approval, keep the requested decision in the main response. Put the supporting explanation in a separate Markdown blockquote: name and link the exact `SKILL.md`, quote the relevant instruction, and briefly explain how it applies. Distinguish the skill's explicit requirement from your interpretation.

Follow higher-priority instructions and the user's explicit formatting preferences if they conflict. Do not create an approval requirement merely to use this format.
